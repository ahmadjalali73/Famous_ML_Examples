Supported File Types:
  • Documents: .txt, .pdf, .md
  • Images: .png, .jpg, .jpeg, .gif
  • Data: .csv, .json, .xml
  • Code: .py, .ipynb
  • Archives: .zip, .tar, .gz
  • ML Models: .pkl, .h5, .pth, .pt
API Usage:

You can also use the REST API for programmatic access:

# Upload a file
curl -X POST "http://localhost:8000/api/upload" -F "file=@your_file.txt"

# List all files
curl "http://localhost:8000/api/files"

# Download a file
curl -O "http://localhost:8000/api/download/your_file.txt"

# Delete a file
curl -X DELETE "http://localhost:8000/api/files/your_file.txt"
